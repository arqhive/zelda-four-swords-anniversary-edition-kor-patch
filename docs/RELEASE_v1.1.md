# v1.1 — 제목 로고·UI 그래픽 한글화

2026-09-20. 북미판 DSiWare `KQ9E`용 누적 패치입니다. **이전 한글 패치본이 아닌 원본에 적용하세요.**

## 변경 내용

- 게임 제목 로고를 **젤다의 전설 / 4개의 검 / 25주년 에디션**으로 한글화했습니다. 원본 분위기를 참고해 ImageGen으로 제작하고, 게임의 256×192 해상도와 기존 색상 팔레트에 맞춰 반영했습니다. 하단 보석과 저작권 표시는 유지했습니다.
- 수련장 지도 이름판 오른쪽에 남아 있던 영문 `L`의 잔여 픽셀을 제거했습니다.
- 파일 복사·삭제 안내를 “어디에 복사할까요?”, “정말 삭제할까요?”로 바꿨습니다.
- 작은 시작·확인 버튼, 뒤로·나가기, 대기 표시, 색 선택의 다른 그래픽 변형을 한글화했습니다. 뒤로는 메뉴 두 사본과 게임 내 별도 사본에 모두 반영했습니다.
- 멀티플레이의 친구 모집·그룹 만들기·그룹 참가·그룹 선택 메뉴를 한글화했습니다.
- 빌드 도구에 타이틀 그래픽 패치를 추가하고, 단계별 그래픽 수정·로고 인코딩 개발 도구를 포함했습니다.

대사와 폰트는 v1.0.1 그대로입니다. 변경된 NitroFS 파일은 `subtask_us_en.cmp`, `zeldat_us_en.bin`, `subtask.cmp` 세 개입니다.

## 확인 내역

- **사용자 에뮬레이터 확인 완료** 후 릴리즈합니다. 모든 해금 상태·멀티플레이 화면을 전수 검증했다는 의미는 아닙니다. 이전 버전의 3DS 실기 확인과 이번 버전의 에뮬레이터 확인은 구분합니다.
- 배포 BPS를 원본에 적용한 결과가 사용자가 확인한 롬과 바이트 단위로 일치합니다.
- 원본에서 소스 빌드 후 배포본과 전체 25개 NitroFS 파일 내용을 비교하여 모두 일치함을 확인했습니다.
- 배포본과 소스 빌드 모두 NTR 섹터·블록·마스터 다이제스트 재계산 결과가 기존 값과 일치합니다. 변경하지 않은 TWL 암호화 영역은 이 검사에서 재계산하지 않습니다.
- 세 그래픽 BPS를 각각 적용한 결과도 배포본 리소스와 일치합니다.

단계별 수정본과 소스 일괄 빌드는 파일 배치와 빈 공간의 데이터가 달라 전체 롬 해시는 다릅니다. 아래 결과 해시는 **배포 BPS 적용 결과**에 대한 값입니다.
