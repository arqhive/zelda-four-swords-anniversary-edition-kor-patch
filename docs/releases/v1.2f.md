메뉴·버튼 그래픽을 전부 다시 그리고 실기로 검수한 완성판입니다. 엔딩까지 플레이해 대사와 안내문을 확인했으며, 더 손볼 곳이 나오지 않아 이 버전으로 작업을 마칩니다. 대사는 힌트 문구 세 개만 길이를 줄였고 나머지는 v1.1과 같습니다.

**원본 북미판 DSiWare에 적용하는 전체 패치입니다.** 이전 한글 패치 파일에 덧씌울 수 없습니다.

## 변경 사항

### 그래픽

- 메뉴 버튼과 안내 문구 26곳을 **Neo둥근모**(좁은 칸은 갈무리)로 다시 그렸습니다. 글자 크기와 외곽 효과를 한 벌로 맞춰, 같은 디자인끼리 제각각이던 모습을 없앴습니다.
- 지도 이름판 7종, 하단 바 7종, 스테이지 선택 제목판을 원본 무늬대로 다시 만들었습니다. v1.1까지는 영문 그래픽 위에 글자를 얹어 바탕이 어긋나 있었습니다.
- 시작 화면의 `PRESS A`를 「Ⓐ 누르기」로 바꿨습니다. A 버튼 기호를 글자 왼쪽으로 옮기고 원본의 세로 그라데이션을 그대로 씁니다.
- 이름 입력 화면의 확인 버튼을 다시 그렸습니다. 글자 자리가 세로 9px뿐이라 갈무리9를 썼습니다.

### 그래픽 손상 수정

v1.1까지는 글자를 넣을 때 사각 영역을 통째로 덮어, 그 안에 있던 그림까지 지워졌습니다. 아래를 모두 원본대로 되살렸습니다.

- 「다 함께 놀기」 버튼 안의 DS 본체 아이콘
- 「삭제」 버튼 왼쪽 꼭지와 윗면 광택
- 「혼자 놀기」 버튼 왼쪽 모서리, 「파일 선택」 판 오른쪽 모서리
- 「뒤로」 위의 B 버튼 기호 (메뉴와 파일 화면 두 곳)
- 「색 선택」 띠 왼쪽의 마름모 장식

글자가 영역 밖으로 삐져나가 「시작」이 위에서 잘리고 「나가기」가 버튼 테두리를 침범하던 것도 함께 고쳤습니다.

## 적용 방법

1. [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/)나 Floating IPS로 북미판 원본에 `.bps` 패치를 적용합니다. 확장자가 `.app`이면 결과 파일을 `.nds`로 바꿉니다.
2. 결과 파일의 확인값을 아래 표와 비교합니다.
3. 3DS나 DSi에서는 TWiLight Menu++의 게임 언어를 English로 설정하고 실행합니다. melonDS에서는 Unlaunch를 거쳐 실행합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.

## 남은 것

- 문 고르는 화면의 `CHOOSE A DOOR` 띠는 영문 그대로입니다. 글자 조각이 잘게 쪼개진 채 흩어져 저장되어 있고, 어느 조각이 화면 어디에 놓이는지 적힌 배치표를 찾지 못했습니다.
- `YOU` 그래픽은 「너」나 「당신」으로 옮기면 어색해서 일부러 영문으로 두었습니다.
- 「다 함께 놀기」(멀티플레이)는 함께 할 사람을 구하지 못해 실제 통신 플레이로 검수하지 못했습니다.
