## 변경 사항

- 대사·안내문·시스템 메시지를 한글화했습니다(220개 항목 중 215개).
- 게임 폰트에 한글 글리프를 추가했습니다.
- 메뉴·타이틀·스테이지 이름판 그래픽을 한글화했습니다.

## 적용 방법

1. [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/)나 Floating IPS로 북미판 원본에 `.bps` 패치를 적용합니다.
2. 결과 파일의 확인값을 아래 표와 비교합니다.
3. 3DS나 DSi에서는 TWiLight Menu++의 게임 언어를 English로 설정하고 실행합니다. 순정 DSi 메뉴에서는 실행되지 않으므로 Unlaunch나 TWiLight Menu++가 필요합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
