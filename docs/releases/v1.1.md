게임 제목 로고와 v1.0.1에서 영문으로 남아 있던 메뉴 그래픽을 한글화한 버전입니다. 대사와 폰트는 v1.0.1과 같으며, 바뀐 NitroFS 파일은 `subtask_us_en.cmp`, `zeldat_us_en.bin`, `subtask.cmp` 세 개입니다. 처음 올린 v1.1은 큰 제목 로고가 영문으로 남아 같은 날 배포 파일을 수정본으로 교체했습니다. 수정 전 v1.1을 받았다면 다시 내려받아 북미판 원본에 적용하세요. 원인과 수정 내용은 [`TITLE_LOGO_FIX.md`](https://github.com/arqhive/zelda-four-swords-anniversary-edition-kor-patch/blob/main/docs/TITLE_LOGO_FIX.md)에 있습니다.

**원본 북미판 DSiWare에 적용하는 전체 패치입니다.** 이전 한글 패치 파일에 덧씌울 수 없습니다.

## 변경 사항

- 게임 제목 로고를 **젤다의 전설 / 4개의 검 / 25주년 에디션**으로 한글화했습니다. 공용 배경뿐 아니라 실제 표시용 스프라이트 두 사본과 부제에도 반영했습니다. 게임의 기존 팔레트·조각 배열·투명도를 쓰며, 보석과 효과 애니메이션 데이터, 저작권 표시는 그대로 두었습니다.
- 수련장 지도 이름판 오른쪽에 남아 있던 영문 `L`의 잔여 픽셀을 지웠습니다.
- 파일 복사·삭제 안내를 「어디에 복사할까요?」, 「정말 삭제할까요?」로 바꿨습니다.
- 작은 시작·확인 버튼, 뒤로·나가기, 대기 표시, 색 선택의 다른 그래픽 변형을 한글화했습니다. 뒤로 버튼은 메뉴의 두 사본과 게임 안의 별도 사본에 모두 반영했습니다.
- 멀티플레이의 친구 모집·그룹 만들기·그룹 참가·그룹 선택 메뉴를 한글화했습니다.
- 빌드 도구에 타이틀 그래픽 패치를 추가하고, 단계별 그래픽 수정과 로고 인코딩에 쓴 개발 도구를 넣었습니다.

## 적용 방법

1. [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/)나 Floating IPS로 북미판 원본에 `.bps` 패치를 적용합니다. 확장자가 `.app`이면 결과 파일을 `.nds`로 바꿉니다.
2. 결과 파일의 확인값을 아래 표와 비교합니다.
3. 3DS나 DSi에서는 TWiLight Menu++의 게임 언어를 English로 설정하고 실행합니다. melonDS에서는 Unlaunch를 거쳐 실행합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
