**원본 북미판 DSiWare에 적용하는 전체 패치입니다.** 이전 한글 패치 파일에 덧씌울 수 없습니다.

## 변경 사항

- 대사 **129개 항목**의 문장을 다듬었습니다.
- 제어 코드(색·아이콘·대기 시간·변수)는 그대로 두었습니다.
- 모든 줄이 대사창 폭(232px) 안에 들어가는지 다시 확인했습니다. 가장 긴 줄은 215px입니다.

## 적용 방법

1. [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/)나 Floating IPS로 북미판 원본에 `.bps` 패치를 적용합니다.
2. 결과 파일의 확인값을 아래 표와 비교합니다.
3. 3DS나 DSi에서는 TWiLight Menu++의 게임 언어를 English로 설정하고 실행합니다. melonDS에서는 Unlaunch를 거쳐 실행합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
