# v1.1 타이틀 스프라이트 누락 수정

사용자 실기 보고: 메뉴는 한글이지만 큰 타이틀 로고는 영문이었다.
v1.1에서 수정한 `subtask.cmp`의 배경 로고 외에, `zeldat_us_en.bin`의
12·13번 항목에 동일한 영문 로고가 별도로 남아 있었다.

## 표시 구조와 변경

- `pat.bin` 그룹 181의 프레임 0: 64×64 스프라이트 여섯 개, 타일 0~383.
- 프레임 1: 64×32 부제 스프라이트 두 개, 타일 384~447.
- 각 객체는 8bpp, 1D 타일 배열이다. 팔레트 인덱스 0은 투명하다.
- `zeldat.bin` 62번 항목의 첫 256색 팔레트를 사용한다.
- 한글 로고를 투명 RGBA로 분리하고 원래 배열에 맞게 인코딩하여 두 항목 모두 교체했다.
- 448번 이후 검·광채·보석 효과 타일, 화면 y=132 이후 본체 보석 픽셀,
  패턴과 팔레트는 원본 그대로 보존했다. 다른 언어별 항목, 메뉴, 대사와 폰트도 바꾸지 않았다.
- `build_title_logo.py`는 이제 `--sprite-artwork`를 필수로 받아 배경과 스프라이트를 함께 처리한다.
  일반 소스 빌드는 갱신된 `patches/gfx/zeldat_us_en.bin.bps`를 적용하므로 제작 이미지는 필요 없다.

## 확인 범위

완성 롬의 두 스프라이트 사본을 다시 추출해 원래 패턴으로 조립했을 때
“젤다의 전설 / 4개의 검 / 25주년 에디션”이 표시됨을 확인했다.
투명도, 1D 타일 배열 왕복, 효과 영역 보존, 다른 리소스 보존,
압축 왕복, 원본→수정 롬 BPS 왕복, 다이제스트 재계산을 검사했다.
사용자가 수정본을 실기에서 실행하여 **한글 로고가 정상 표시됨을 확인했다**.
일반 소스 빌드와 배포본의 전체 25개 NitroFS 파일 내용도 일치한다.

갱신한 v1.1 배포 ROM SHA1: `9ccbaed11f2b045655e5cb2b23c1622a77b099cc`.
사용자 요청에 따라 버전은 v1.1로 유지하고 배포 파일과 태그를 수정본으로 교체했다.
기존 v1.1을 받은 사용자는 패치를 다시 내려받아 북미판 원본에 적용해야 한다.
제작 이미지와 비교 이미지는 저장소에 포함하지 않는다.
